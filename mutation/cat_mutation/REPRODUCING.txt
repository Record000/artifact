CAT mutation reproduction
=========================
Run these commands from the downloaded artifact repository root.

A. Recompute historical numbers (Python 3 only, no validators)
python3 mutation/cat_mutation/reproduce_reference.py /tmp/cat-reference
Output: /tmp/cat-reference/cat_mutation_stats.csv
Input: reference_results.tar.gz, containing exactly the 1000 result.json files
from exp_cureasn1/results/fix_cure_v2. These are archived summary records, not
new experimental runs or raw validator logs. This reproduces the reported
statistics, not an independent verification of historical log parsing.

B. New randomized experiment (Linux x86_64)
System dependencies: Python >=3.10 with venv/pip, Rust/Cargo on PATH, C linker,
rsync, openssl, glibc >=2.39 and shared libraries required by RP/instruct:
libjansson.so.4, libcurl.so.4, libxml2.so.2, libmicrohttpd.so.12,
libcrypto.so.3, libssl.so.3, libz.so.1, libexpat.so.1, libtls.so.22.
Use ldd RP/instruct/{fort,routinator,octorpki,rpki-client} to inspect your host.
The bundled ELF binaries do not run natively on macOS or ARM.

python3 mutation/cat_mutation/prepare_workspace.py /tmp/cat-run
python3 mutation/cat_mutation/run_campaign.py /tmp/cat-run --repos 1000
Output: /tmp/cat-run/results/cat_mutation_stats.csv
Per-repository summaries and logs: /tmp/cat-run/results/cat_mutation/
Use another NEW workspace and --repos 1 for smoke testing first.
Preparation installs Python dependencies and builds the Rust mutator from
vendored source with Cargo.lock. Network access is needed for pip/Cargo.
No dependency on the author's original experiment directory is required.
Port 8730 must be free. The runner starts/stops only its own loopback rsync
process; it does not stop existing services. Do not run campaigns concurrently.
Run as an ordinary user. All generated objects, keys, caches and logs remain
in the external workspace. Existing campaigns are not overwritten.

Older Linux hosts can explicitly set CAT_LOADER and CAT_LOADER_LIBS for a
compatible standalone loader, and CAT_LIBRARY_PATH for extra shared libraries.
These are optional user-supplied runtime paths, not bundled prerequisites.

Semantics: --rounds 7 --ta-rounds 3 --include-ta --types cer --repair
--post-rebuild, 1000 repositories, start=1. Each validator is captured separately;
the statistic is max stage per repository, not per object. Repair failures stay
in the measurement; infrastructure/generation failures stop the new runner.
Seeds do not fix secrets-generated names or cryptographic key generation.
A new run is not guaranteed to reproduce historical percentages exactly.
Current source snapshots also are not proof of the exact historical executable
source identity. SOURCE_MANIFEST.json records the initial imported sources and
hashes; subsequent packaging changes are tracked by Git, not that old manifest.

Checks performed: Python syntax, Rust release build from vendored source, fresh
Python environment, historical 1000-record aggregation, and one-repository
smoke on the existing Linux server using its optional standalone glibc loader.
No fresh glibc>=2.39 machine or new 1000-repository campaign has been tested.
